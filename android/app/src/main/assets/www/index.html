1. Executive Summary

This document demonstrates the desktop-grade capabilities of Word Studio Pro running on Android tablets, foldables, and desktop workstations. Unlike basic mobile note editors, this workspace provides a true A4 / US Letter paged canvas, an interactive horizontal margin ruler, deep physical keyboard shortcut interception, and on-screen virtual keyboard suppression.

“Productivity on foldable devices and tablets with Bluetooth or USB-OTG folio keyboards requires zero-latency hardware shortcuts (Ctrl+B, Ctrl+S, Tab cell cycling) without the software keyboard covering 50% of the viewport.”

3. Deep Hardware Keyboard & Soft Keyboard Controls

  • Formatting Shortcuts: Press Ctrl+B (Bold), Ctrl+I (Italic), Ctrl+U (Underline), Ctrl+Shift+> (Grow Font), or Ctrl+E / L / R / J for paragraph alignment.
  • Table Navigation: Click inside any table cell above and press Tab or Shift+Tab to jump across cells, or press Enter at the end of the table to append a new row.
  • Virtual Keyboard Lock: Toggle the floating Soft Keyboard: Hidden / Active button in the bottom-right corner to lock out the on-screen keyboard while typing on a physical keyboard.
